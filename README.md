## About the Project

This project classifies heart conditions from ECG (electrocardiogram) signals using machine learning. The work covers:

- Preparing and augmenting ECG signal data (MIT-BIH database)
- Extracting features from the signal (P, Q, R, S, T waves, their positions and the distances between them)
- Training and comparing four classifiers: SVM, KNeighbors, Decision Tree and Random Forest
- Classifying three cases: **Normal**, **PVC** (Premature Ventricular Contraction) and **LBBB** (Left Bundle Branch Block)

The Random Forest classifier gave the best results and was adopted (about 86% test accuracy).

The full project report (Arabic original, with an English translation) describes the method and results in detail.
